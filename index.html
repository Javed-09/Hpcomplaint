Leave empty to use Demo Mode. See README.md for the full setup guide (create Sheet → add Apps Script → deploy as Web App → paste URL here).

Disconnect (use demo mode)
Security note. A Google Apps Script Web App used this way is a public endpoint: anyone who obtains the URL can read and write all complaint data. A secret stored in this frontend's JavaScript is not secure (it is visible in the page source). Keep the URL private and share it only with authorised coordinators. Static hosting cannot provide real user authentication — see README.md for details and alternatives.

About

Huff & Puff Burger — Complaint Management System
Version
Static website: HTML5 + CSS3 + vanilla JavaScript (no frameworks, no build tools).
Database: Google Sheets via Google Apps Script Web App (free), with a clearly-labelled browser-only Demo Mode fallback.
Charts by Chart.js (free CDN) — the app keeps working if the CDN is unavailable.

Files: index.html · style.css · script.js · config.js · demo-data.js · google-apps-script.gs · README.md
